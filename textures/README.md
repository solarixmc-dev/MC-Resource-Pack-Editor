# Default Textures for Create from Scratch

To enable the "Create from Scratch" feature to load default textures automatically:

1. Download the official Minecraft Vanilla Resource Pack (16x16)
2. Rename the downloaded file to `default-pack.zip`
3. Place it in this folder: `public/textures/default-pack.zip`

## Where to get default textures:

You can download the official Minecraft vanilla resource pack from:
- Minecraft Wiki: https://minecraft.wiki/w/Default_resource_pack
- Or extract from your Minecraft installation:
  - Windows: `%appdata%\.minecraft\versions\[version]\[version].jar`
  - Mac: `~/Library/Application Support/minecraft/versions/[version]/[version].jar`

## Alternative:

If you don't want to add the default pack, the "Create from Scratch" button will fall back to downloading from CurseForge as before.

## Note:

The default pack should be a standard Minecraft resource pack with the standard folder structure:
- assets/minecraft/textures/
- pack.png (optional)
- pack.mcmeta (optional)
